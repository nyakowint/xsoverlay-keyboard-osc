Version 2.0.1 is the last version of this very OSC Chatbox plugin. 

- XSOverlay has a new web based keyboard! (added in beta 692+)
  - It has official support for both STT (speech-to-text) and manual typing.
  > When playing VRChat while OSC is enabled, you should now see a VRC Chatbox toggle next to the pin button. Turning this on will make any text in the input field go to the vrchat chatbox when you hit send, so long as OSC is enabled in VRChat. You may type into the field manually, or use speech to text to populate it.
    - In my opinion, the whisper setup used by this STT is very generic and awful at it's job (understanding vrchatters), so the humble manual typing is the best migration path for people who used my plugin :D

This prerelease build of the plugin removes all keyboard patching functionality. Why did i release this? Well i didn't want to leave ya on a cliffhanger. :P
