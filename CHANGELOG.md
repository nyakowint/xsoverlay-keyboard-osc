Version 1.4.0 is the final stable release of my OSC keyboard plugin. Yes the one you are looking at right now.

This version adds a timegate/killswitch to disable all error-prone functionality on builds newer than 680 (current stable build).

**Why,** you may ask...?

## XSOverlay now has official support for typing into VRChat's chatbox!
It is currently in the `beta` branch on steam if you want to use it instead.

## What does this mean for the plugin?
Effective as soon as the beta becomes stable, this plugin will become defunct and obsolete.

Updating to this version is optional but recommended for a smooth plugin -> official feature migration experience.
