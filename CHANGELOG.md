Version 2.0.0 is a rewrite for XSOverlay's new web based keyboard (beta 688+).

> [!IMPORTANT]
This version only works on XSOverlay versions `688` and newer! (currently beta)

small summary of changes:
- Preliminary support for new keyboard ui
- Yoinked the incoming STT features text input for chatbox input aswell
  - fun fact: you can send to vrchat with the STT by speaking, clicking the chat bubble, then pressing send/enter.
  - the whisper setup used in xso has a hard time understanding vrchatters, so uh good luck
- caret movement and actions should work *sometimes*, i couldn't figure it out reliably
- Text macros now has its own dropdown menu (the shortcut texts still work)
- Gave function to the random copy and paste buttons on the right of the keyboard (same function as before)
- Plugin settings moved into XSOverlay's own Keyboard settings page in a Chatbox section
- END key only sends chatbox clear when the bar is empty (it moves the caret otherwise)
- probably more i kinda rushed to get this working
